# Catmint for VS Code

Syntax highlighting for `.cm` and `.cmm` files: keywords, class names, strings (with
`${...}` interpolation), comments, numbers, and `def` names. Indentation follows the
blocks that end in `:` and `end`.

## Install

Either link the folder into VS Code's extensions folder and restart it:

    ln -s "$PWD" ~/.vscode/extensions/catmint-0.1.0        # from this folder

or package it and install the file (needs Node):

    npx @vscode/vsce package && code --install-extension catmint-0.1.0.vsix

## Keeping it right

`syntaxes/catmint.tmLanguage.json` is generated by `tools/make_vscode.py`, which reads the
keywords from the lexer (`catmint-lex/catmint.l`), so the grammar cannot drift from the
language. A new keyword stops the script until it is given a colour in the table there.
`test.sh` runs `tools/make_vscode.py --check`. The other two files are written by hand.

The grammar is checked by `tools/vscode_test.py`, which applies its patterns to the sample
in `tests/sample.cm` and compares the scopes it finds with `tests/sample.scopes`.
